## 🎯 部署步骤（按顺序执行）

### **第一步：在阿里云主机上准备环境**

```bash
# 1. 登录主机后，进入项目目录
cd /root/epic-bot  # 或你的项目目录

# 2. 创建虚拟环境（如果还没有）
python3 -m venv .venv
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt
```

---

### **第二步：配置飞书机器人**

```bash
# 1. 复制示例配置文件
cp config/feishu_bot_config.example.json config/feishu_bot_config.json

# 2. 编辑配置文件，填入你的信息
vim config/feishu_bot_config.json
```

**配置文件内容：**
```json
{
  "app_id": "cli_a9449b8d74bb1bd3",
  "app_secret": "这里填你的App Secret",
  "verification_token": "这里填你的Verification Token",
  "encrypt_key": "这里填你的Encrypt Key（可选，没有就留空）",
  "bot_name": "Epic",
  "host": "0.0.0.0",
  "port": 9000,
  "domain": "feishu.epicarena.cn"
}
```

---

### **第三步：配置Nginx**

```bash
# 1. 复制配置文件到Nginx目录
sudo cp deploy/nginx.conf /etc/nginx/sites-available/feishu-bot

# 2. 创建软链接启用站点
sudo ln -s /etc/nginx/sites-available/feishu-bot /etc/nginx/sites-enabled/

# 3. 测试Nginx配置
sudo nginx -t

# 4. 如果测试通过，重启Nginx
sudo systemctl restart nginx
```

---

### **第四步：配置Systemd服务**

```bash
# 1. 复制服务文件
sudo cp deploy/feishu-bot.service /etc/systemd/system/

# 注意：如果你的项目路径不是 /root/epic-bot，需要修改服务文件中的路径！

# 2. 重新加载systemd
sudo systemctl daemon-reload

# 3. 启用开机自启
sudo systemctl enable feishu-bot

# 4. 启动服务
sudo systemctl start feishu-bot

# 5. 查看服务状态
sudo systemctl status feishu-bot
```

---

### **第五步：配置飞书开放平台回调地址**

1. 登录 [飞书开放平台](https://open.feishu.cn/)
2. 进入你的应用 → **事件订阅**
3. 设置 **请求地址（URL）**：
   ```
   http://feishu.epicarena.cn/webhook/event
   ```
   *(后续申请SSL证书后改为 https)*
4. 点击 **验证** 按钮
5. 添加需要订阅的事件：
   - `im.message.receive_v1` - 接收消息
6. 保存配置

---

### **第六步：配置机器人权限**

在飞书开放平台 → **权限管理**，添加以下权限：
- `im:message` - 发送消息
- `im:message.group_at_msg` - 群组@消息
- `im:message.p2p_msg` - 单聊消息

## 🔧 常用命令

### 查看服务日志
```bash
# 查看最新日志
sudo journalctl -u feishu-bot -n 50 -f

# 查看今天的日志
sudo journalctl -u feishu-bot --since today
```

### 重启服务
```bash
sudo systemctl restart feishu-bot
```

### 停止服务
```bash
sudo systemctl stop feishu-bot
```

### 检查Nginx日志
```bash
# 访问日志
sudo tail -f /var/log/nginx/feishu-bot-access.log

# 错误日志
sudo tail -f /var/log/nginx/feishu-bot-error.log
```

## 🆘 故障排查

### 问题1：服务无法启动
```bash
# 查看详细错误
sudo journalctl -u feishu-bot -n 100 --no-pager
```

### 问题2：飞书回调验证失败
- 检查Nginx是否运行：`sudo systemctl status nginx`
- 检查机器人服务是否运行：`sudo systemctl status feishu-bot`
- 查看Nginx错误日志：`sudo tail -f /var/log/nginx/feishu-bot-error.log`

### 问题3：能收到消息但不回复
- 检查Agent配置是否正确
- 查看服务日志：`sudo journalctl -u feishu-bot -f`
